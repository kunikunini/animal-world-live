# ANIMAL WORLD LIVE

**「世界中の動物たちと、友達になろう。」**

美しい3Dのサバンナを歩いて、実在するライオンたちと出会い、プロフィールを知り、自分の意思で「ともだちになる」を押して、ともだち帳からいつでも会いに行ける。そんなWebプロトタイプです。

Built with Claude: Japan 2026 の提出作品として、ハッカソン期間中（2026-11-02 以降）に新規制作しています。

## いま動くもの

- 青空と金の草原のサバンナをどこでも歩ける（タップ／クリックで移動、WASD でも移動、Space か「ジャンプ」で跳ぶ。ドラッグで視点を回し上下にも向け、ホイールで寄る）
- 左上のミニマップと「地図を広げる」の全体地図。地図はレーダーではなく出会いの記録で、出会った動物だけが載る（ともだちは区別）。タップした場所へ歩ける
- ライオンの家族5頭が様式化した姿でワールドにいる（台地にアンジーと双子、少し離れてアレックス、水場のそばにライリー）。近づくと名前が出て、そばに来ると「双眼鏡で見る」からその個体の観察モニターへ。3Dの姿は本物の行動を写したものではなく、出会いの「しるし」
- コピエ（岩山）の観察スポットへ自動移動し、観察モニターで映像を見る（「収録映像」バッジ常時表示）
- 個体のプロフィール（家族・見分けポイント・飼育員コメント。原稿が入るまでは「準備中」と表示）
- 自分の意思で「ともだちになる」→ ともだち帳に記録（localStorage）→「会いに行く」で3Dを歩かずに映像へ再訪

## 映像について

このプロトタイプで使う動物映像は、ハッカソン期間中に収録した**収録映像**です。ライブ配信ではありません。映像・写真はこのリポジトリには含まれていません（`public/media/` は `.gitignore` 済み）。

開発中は、色と文字だけの自作プレースホルダ映像を使っています。生成するには ffmpeg を入れて次を実行します（実写や外部の素材は使いません）。

```bash
./scripts/make-placeholder-video.sh
```

## データの出所

ライオンの個体情報は、協力施設の飼育記録から、公開してよい項目だけを静的データとして抽出したものです（施設名の表記は確認中）。個人情報は含みません。

## 技術

Vite + TypeScript + Three.js。世界はすべて手続き生成（外部3Dアセットは使っていません）。

### 3D モデルの生成（実験）

`tools/blender/angie_v2.py` は Blender 5.2 の Python で動かすスクリプトで、様式化したライオンをコードだけで造形し glTF に書き出します（外部の 3D 素材は使いません）。`?lion=v2` を付けて開くと `public/models/angie-v2.glb` に差し替わり、読めなければプリミティブ版のまま動きます。

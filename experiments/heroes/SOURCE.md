# 素材の出所

- `inputs/<id>/front.png`: 期間中に用意したキービジュアルの子どものキャラクターシート（`artwork/children-character-sheets/binoculars/` の 3 面図・通常の顔。くにが渡したデスクトップの `X.png` と md5 一致）から、正面のビューだけを切り出して 1000×1000 の白地に置いたもの（拡大・縮小なし）。Meshy の入力に使用。シートそのもの（`artwork/`）はリポジトリに入れない
  - `teal`: `02_青緑ジャケットの子_双眼鏡版.png`（1774×887）の x 58–593・y 19–864
  - `pink`: `03_ピンク服の子_双眼鏡版.png`（1536×1024）の x 36–534・y 57–959
  - `bluecap`: `04_青い帽子の子_双眼鏡版.png`（1774×887）の x 71–581・y 20–867
  - `purple`: `05_紫服の子_双眼鏡版.png`（1536×1024）の x 35–550・y 62–969
  - `braids`: `06_三つ編みの子_双眼鏡版.png`（1774×887）の x 77–550・y 14–869
- `public/heroes/<id>.webp`（ホームの「だれで冒険する？」の絵）: 同じシートの正面から頭と肩のまわり（全身の高さの 46% 四方）を切り出して 144×144 の WebP にしたもの。黄色い子は `01_黄色ジャケットの子_双眼鏡版.png` から
- `public/models/hero-<id>.glb`: 上の入力から Meshy（Pro）の Image to 3D で生成し、ヒューマノイドのリグ（身長 1.2 m）と、リグの時に自動で付いた「歩く」「走る」を付けてダウンロードし（スケルトンのテンプレートは Mixamo）、gltf-transform で最適化したもの。**生成時のライセンス設定は「プライベート」**（黄色い子・ライオンと同じ）
- `raw/`: Meshy から落としたままの GLB（コミットしない）
- `shots/<id>/meshy-*.jpg`: Meshy の画面を撮ったもの。`shots/<id>/world-*.jpg`: このプロジェクトのゲーム画面

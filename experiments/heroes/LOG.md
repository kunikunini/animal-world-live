# heroes 実験ログ（ブランチ exp/heroes、main 非マージ）

キービジュアルの子どものうち、黄色いジャケットの子（main 統合済み）以外の 5 人を、黄色い子と同じレシピで 3D にする。あわせて主人公を名簿にし、ホームで「だれで冒険する？」を選べるようにする。

- 入力: `artwork/children-character-sheets/binoculars/` の 3 面シート（くにが渡した `X.png` の通常の顔と同じファイル、md5 一致）から正面のビューだけを切り出し、1000×1000 の白地に拡大・縮小なしで置いた（`inputs/<id>/front.png`）。シート丸ごとは入れていない
- Meshy: 黄色い子と同じ（スマートトポロジー / Meshy T2.5 / ポリゴン数 10000 / テクスチャあり Meshy N1・2K / ポーズ指定なし / ライセンス プライベート）。リグはヒューマノイド・身長 1.2 m。ダウンロードは glb / スケルトンのテンプレート Mixamo / リグドキャラクター オフ / アニメーション すべて追加 / 単一ファイル
- 待機・ジャンプは黄色い子と同じコードの代わり（止まっている時は立ち姿、空中は走りの両足が浮いたコマ）。Meshy での追加は試していない
- 最適化: `gltf-transform optimize <in> <out> --compress meshopt --texture-compress webp --texture-size 1024 --simplify-ratio 0.95 --simplify-error 0.001`（4.5.1、黄色い子・ライオンと同じ）
- ワールド: `src/data/heroes.json` に 1 行足すだけ（モデル・ホームの絵・高さの倍率・見た目の呼び名）。材質のトゥーン化と分離（接地影＋細い輪郭）は `heroModel.ts` の同じ仕組み
- 撮影: dev サーバー（`exp/heroes`）をヘッドレス Chrome（ソフト描画、DPR 1）で。正面・斜め・後ろは PC 1024×768 で主人公の向き基準の固定カメラ、歩き・走りはスマホ幅 390×844 の追従カメラ
- `raw/`（Meshy から落としたままの GLB）はコミットしない
